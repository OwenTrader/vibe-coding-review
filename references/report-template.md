| 项 | 内容 |
|----|------|
| 审查范围 | （commit/diff/目录/文件清单） |
| 审查维度 | （本次启用的维度列表） |
| 审查时间 | |
| 总体结论 | ✅ 可合并 / ⚠️ 修复 P0-P1 后可合并 / ❌ 存在阻断问题 |
